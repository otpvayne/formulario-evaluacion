# Formulario con Validación y Tailwind

Este proyecto es un ejemplo de formulario con validación básica usando JavaScript, TailwindCSS y `fetch()` con `async/await`.

## ¿Cómo ejecutarlo?

1. Clona el repositorio.
2. Abre `index.html` en tu navegador.
3. Completa el formulario y envíalo.

## Funcionalidades

- Validación de campos no vacíos
- Envío simulado a una API falsa
- Estilo responsivo con Tailwind
